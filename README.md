# DB-RentalCamera
RentalCam adalah aplikasi web untuk mengelola penyewaan kamera menggunakan PHP dan MySQL. Fitur utamanya meliputi login admin dan petugas, manajemen data kamera, pelanggan, kategori, petugas, transaksi sewa, perhitungan biaya, diskon, denda keterlambatan, otomatisasi stok, serta laporan pendapatan bulanan dengan antarmuka dark mode yang responsif.
